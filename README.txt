# Survivor Challenge PWA

Sube **todos** los archivos y la carpeta `icons` a la raíz de tu repositorio de GitHub Pages, conservando sus rutas. El archivo `index.html` reemplaza al anterior. Mantén también `survivor_header.png` y cualquier archivo `data/` que ya use tu sitio.

Abre https://galavizalbert.github.io/survivor-picks/ por HTTPS.

- Android Chrome: menú > Instalar app (o usa el botón Instalar app del menú cuando aparezca).
- iPhone Safari: Compartir > Añadir a pantalla de inicio > Añadir.

El modo sin conexión solo muestra la interfaz almacenada; datos, autenticación, picks y pagos necesitan Supabase/internet. Los datos no se almacenan para edición offline. El HTML existente conserva su configuración de Supabase. Para controles de comisión compartidos y seguros, sigue siendo necesario ejecutar el SQL suministrado anteriormente.
